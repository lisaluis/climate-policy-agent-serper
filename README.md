# Climate Policy Agent — Serper version

A starter project for multi-source climate, air-pollution and environmental policy research in India, with Goa-specific recommendations when relevant.

## What it does
1. Accepts a policy question through a static website.
2. Calls a FastAPI backend.
3. Uses Serper web search and displays result titles, URLs and snippets.
4. Produces transparent, rule-based suggestions with limitations.

## Important limitations
- Search snippets do not replace reading the linked source.
- Source-quality hints are heuristics, not proof of correctness.
- Recommendations are rule-based, not generated by a fine-tuned LLM.
- Verify publication dates, methods, local data and current laws before using recommendations.
- The prototype does not calculate emissions reductions, costs or causal effects.

## Deploy backend on Render
1. Get an API key from the official Serper account dashboard.
2. Push this project to the new duplicate repository, not the original.
3. Create a Render Web Service connected to the new repository.
4. Set root directory to `backend`.
5. Build command: `pip install -r requirements.txt`
6. Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
7. Add `SERPER_API_KEY` in Render Environment with your real key.
8. After Pages is configured, set `FRONTEND_ORIGIN` to the Pages origin, e.g. `https://YOUR-USERNAME.github.io` (origin only, no path).
9. Deploy, then test `/health` and `/docs` on the Render URL.

## Connect frontend
1. In `website/app.js`, replace `https://YOUR-RENDER-SERVICE.onrender.com` with your actual Render service URL.
2. Commit the change to the new repository.
3. In GitHub Settings > Pages, publish the `website` folder if the source options allow it. Otherwise copy the three website files to the root of the new repository and publish the root, or configure a Pages GitHub Actions workflow.
4. Test with: “What policies could help Goa reduce air pollution while supporting sustainable tourism?”

## Local development (PowerShell)
```powershell
cd backend
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:SERPER_API_KEY="YOUR_REAL_KEY"
$env:FRONTEND_ORIGIN="*"
uvicorn main:app --reload
```
Then test `http://127.0.0.1:8000/docs`. For a local browser test, set `API_BASE_URL` in `website/app.js` to `http://127.0.0.1:8000` and serve the website folder using a local static server.

## Security
Never place the Serper key in frontend JavaScript, HTML or a committed file. Never commit `.env`. If a key is exposed, revoke or rotate it.
